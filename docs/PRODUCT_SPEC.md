# Product Specification

## Positioning

**AI that remembers your work, not just your chats.**

The primary object is a workspace, not an individual conversation. Workspaces accumulate conversations, durable memories, files, decisions, and eventually connectors.

## MVP journeys

### Start a workspace
Create/open a workspace and start chatting immediately.

### Capture durable state
As conversation evolves, important facts, preferences, requirements, constraints, and decisions appear in Memory Inspector.

### Correct the AI
Users can inspect the source of a memory, edit it, pin it, or mark it obsolete.

### Understand change
Memory history shows how important decisions evolved over time.

## Later phases

- Authentication and organizations
- File ingestion and document-grounded memory
- GitHub / Google Drive / Gmail / Slack connectors
- Shared team workspaces
- Scheduled agents and task execution
- Billing and usage quotas
- Memory export/import API
